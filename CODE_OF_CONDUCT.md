# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and kind. Welcome beginners; everyone started somewhere.
- Disagree about ideas, never attack people.
- No harassment, insults, spam or sharing other people's private information.
- Do not post account credentials, cookies, or pirated content in issues or PRs.

The maintainer may edit or remove comments, issues or PRs that break these rules, and may block repeat offenders.

To report a problem, contact the maintainer through GitHub (open a private security report, or mention @atish23 in an issue if it is not sensitive).
